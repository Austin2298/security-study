## 리눅스 기본 명령어 정리

### ls
현재 디렉터리에 있는 파일과 폴더 목록을 확인.

### ls -al
현재 디렉터리에 있는 파일과 폴더와 "숨김 파일"을 자세히 확인.

### cd
디렉터리 이동.

### cat
파일 내용 출력.

### file
파일 종류 확인.

### find
조건에 맞는 파일 찾기.

### grep
파일 안의 특정 문자열이 들어간 줄 찾기.

### sort
텍스트 정렬.

### uniq
중복된 줄 처리.

### ssh
원격 서버 접속.

### exit
현재 접속 중인 서버나 터미널 세션 종료.
