# Bandit 0~8 풀이 메모

## 0 -> 1
### 목표
VSC 터미널에서 SSH로 bandit0 계정에 접속한 뒤, readme 파일을 읽을 수 있다.
### 새로 사용한 명령어
ssh bandit0@bandit.labs.overthewire.org -p 2220 # 계정 접속
ls # 파일 탐색
cat readme # 파일 읽기

## 1 -> 2
### 목표
파일 이름에 -이 들어간 파일을 읽을 수 있다.
### 새로 사용한 명령어
cat ./- # ./은 -을 파일명임을 명확히 지정한다.

## 2 -> 3
### 목표
공백과 --가 포함된 파일명을 읽을 수 있다.
### 새로 사용한 명령어
cat -- "--spaces in this filename--" # 앞의 --는 이 뒤가 옵션이 아닌 파일명이란 신호다.

## 3 -> 4
### 목표
디렉터리 안의 숨김 파일을 찾을 수 있다.
### 새로 사용한 명령어
ls -al # ls 뒤의 -al로 숨김 파일까지 자세히 볼 수 있다.

## 4 -> 5
### 목표
디렉터리 안의 여러 파일 중 사람이 읽을 수 있는 파일을 찾을 수 있다.
### 새로 사용한 명령어
file ./* # ./로 현재 디렉터리의 파일을 명확히 지정할 수 있다.

## 5 -> 6
### 목표
디렉터리에서 다음 조건에 맞는 파일을 찾을 수 있다: [사람이 읽을 수 있음, 1033 bytes, 실행 파일이 아님]
### 새로 사용한 명령어
find . -type f -size 1033c ! -executable # find: 조건에 맞는 파일 검색, -type f: 일반 파일만, -size 1033c: 1033바이트 크기의 파일, ! -excutable: 실행 파일이 아닌 파일

## 6 -> 7
### 목표
서버 전체에서 다음 조건에 맞는 파일을 찾을 수 있다: [user: bandit7, group: bandit6, size: 33 bytes]
### 새로 사용한 명령어
find / -user bandit7 -group bandit6 -size 33c 2>dev/null # -user: 파일 소유자, -group: 파일 그룹, 2>/dev/null: 권한 오류 메시지 숨김

## 7 -> 8
### 목표
텍스트 파일에서 특정 단어 옆을 찾을 수 있다.
### 새로 사용한 명령어
grep millionth data.txt # grep은 파일 안에서 특정 문자열이 포함된 줄을 찾는 명령어이다.

## 8 -> 9
### 목표
텍스트 파일에서 딱 한 번만 등장하는 줄을 찾을 수 있다.
### 새로 사용한 명령어
sort data.txt | uniq -u # sort로 텍스트를 정령한 후 |로 앞 명령어의 결과를 뒤 명령어로 전달하고 uniq -u로 한 번만 등장한 줄만 출력한다.
